Try FiroGate without real money.

Every demo is a private sandbox in your browser. Payments use fake FIRO, and everything is deleted after 24 hours.

API docs

What you can try

The full dashboard, with sample orders.

Dashboard
Payments, analytics, refunds, recurring payments and settings.
Checkout
Open any payment page and pay it with one tap.
API
Create payments from your own code with a demo API key.
Webhooks
Get real signed webhooks at your own URL to test your handler.
Spark mints
Pay a transparent invoice, then simulate a mint.

Real or fake

So you know what to expect.

Payments
Fake. No FIRO moves, and nothing is on a blockchain.
Webhooks
Real and signed, up to 200 a day.
Keys
The API key and wallet keys only work in this demo.

How a demo works

No sign-up.

  1. Start a demoOne click opens your own sandbox.
  2. Look aroundSample orders are already there.
  3. Pay a checkoutUse the demo buttons to pay or mint.
  4. LeavePress End demo when you are done.

Privacy

There is no account. Your demo is tied to a cookie in this browser.

Your IP address is only kept as a hash, to limit how many demos start each hour.
